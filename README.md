# Список задач

Мой первый проект на React. Небольшое приложение для добавления, редактирования, выполнения, фильтрации и удаления задач. Данные сохраняются в `localStorage` текущего браузера. При первом открытии показаны четыре примера; прежние задачи из ключа `state` автоматически подхватываются.

## Локальный запуск

```sh
yarn install
yarn dev
```

Проверка: `yarn build` и `yarn lint`.

Публикация на [GitHub Pages](https://detkovvv.github.io/to_do_list/) выполняется workflow при обновлении ветки `master`.
